Custom WordPress LMS

Challenge: Corporate training provider needed a scalable platform for 5,000+ users with video progress tracking and quiz automation.
Action: Built custom WordPress LMS using LearnDash + custom PHP modules, integrated Zoom API for live classes, optimized database for concurrent users.

Shopify Speed Optimization

Challenge: Beauty brand’s Shopify store had 45 Lighthouse score, high bounce rate (68%) on mobile due to bulky apps & unoptimized assets.
Action: Removed redundant apps, deferred non-critical JS, converted images to WebP, implemented lazy loading, leveraged Shopify’s native caching.
Result: Lighthouse score soared from 45 → 92, conversion rate ↑ 28%, and page load time reduced from 4.2s to 1.3s.
